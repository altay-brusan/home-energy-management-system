# Clean Architecture Prompts

## Yeni Feature Ekleme
```
Bu Clean Architecture projesine yeni bir {FeatureName} feature'ı ekle. 
Kurallara uygun şekilde:
1. Domain entity'si oluştur
2. Application Commands/Queries yaz
3. Validators ekle
4. Infrastructure DbSet ekle
5. Web Endpoints oluştur
6. Tests yaz
```

## Code Review
```
Bu kodu Clean Architecture kurallarına göre review et:
- Katman bağımlılıkları doğru mu?
- Naming conventions uyuldu mu?
- Security kuralları uygulandı mı?
- Performance optimizasyonları var mı?
```

## Refactoring
```
Bu kodu Clean Architecture prensiplerine göre refactor et:
- SOLID prensiplerini uygula
- Dependency Inversion kullan
- Separation of Concerns sağla
```
