# ProcessDeviceAlarm API Endpoint

## Overview

The `ProcessDeviceAlarm` endpoint receives alarm notifications from IoT devices (via Node-RED) and processes them into structured device notifications stored in the database.

## Endpoint Details

**URL:** `POST /api/device-notifications/alarm`

**Authorization:** Device-only (requires device authentication token)

**Content-Type:** `application/json`

## Request Body

The endpoint expects an `InverterAlarmState` JSON structure as generated by the Node-RED flow.

### InverterAlarmState Schema

```json
{
  "timestampUtc": "2025-12-21T20:30:00Z",
  "gatewayId": "EC100",
  "inverterSerialNumber": "INV-12345",

  "runStateRaw": 3,
  "warningWord1Raw": 0,
  "warningWord2Raw": 0,
  "faultWord1Raw": 16,
  "faultWord2Raw": 0,
  "faultWord3Raw": 0,
  "faultWord4Raw": 0,

  "activeAlarms": [
    {
      "code": 1005,
      "vendorCode": 4,
      "severity": "fault",
      "sourceDevice": "grid",
      "category": "ac_voltage",
      "messageKey": "GRID_VOLTAGE_HIGH",
      "messageParams": {
        "measuredValue": 253.5,
        "limitValue": 253.0
      },
      "firstOccurredUtc": "2025-12-21T20:29:45Z",
      "lastOccurredUtc": "2025-12-21T20:30:00Z",
      "occurrenceCount": 3
    }
  ]
}
```

### Field Descriptions

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `timestampUtc` | string (ISO 8601) | Yes | Timestamp when alarm state was captured |
| `gatewayId` | string | Yes | IoT gateway identifier |
| `inverterSerialNumber` | string | Yes | Inverter serial number |
| `runStateRaw` | integer | Yes | Inverter run state (0=standby, 1=selfcheck, 2=normal, 3=alarm, 4=fault) |
| `warningWord1Raw` | integer | Yes | Raw warning register 653 value |
| `warningWord2Raw` | integer | Yes | Raw warning register 654 value |
| `faultWord1Raw` | integer | Yes | Raw fault register 655 value |
| `faultWord2Raw` | integer | Yes | Raw fault register 656 value |
| `faultWord3Raw` | integer | Yes | Raw fault register 657 value |
| `faultWord4Raw` | integer | Yes | Raw fault register 658 value |
| `activeAlarms` | array | Yes | List of currently active alarms |

### ActiveAlarm Schema

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `code` | integer | Yes | Internal alarm code (e.g., 1001-1016 for faults, 2001-2010 for warnings) |
| `vendorCode` | integer | Yes | Bit position in the fault/warning word |
| `severity` | string | Yes | "fault" or "warning" |
| `sourceDevice` | string | Yes | Source of alarm: "inverter", "battery", "grid", "pv" |
| `category` | string | Yes | Alarm category (e.g., "ac_voltage", "dc_voltage", "over_temp", "frequency") |
| `messageKey` | string | Yes | Message lookup key (e.g., "GRID_VOLTAGE_HIGH") |
| `messageParams` | object | No | Additional parameters (measuredValue, limitValue, etc.) |
| `firstOccurredUtc` | string | Yes | First occurrence timestamp |
| `lastOccurredUtc` | string | Yes | Most recent occurrence timestamp |
| `occurrenceCount` | integer | Yes | Number of times this alarm has occurred |

## Response

### Success Response (200 OK)

```json
{
  "success": true,
  "processedCount": 1,
  "createdCount": 1,
  "errors": []
}
```

### Response with Partial Errors (200 OK)

```json
{
  "success": false,
  "processedCount": 3,
  "createdCount": 2,
  "errors": [
    "Notification type not found for alarm code 9999 (UNKNOWN_ALARM). Skipping."
  ]
}
```

### Response Fields

| Field | Type | Description |
|-------|------|-------------|
| `success` | boolean | `true` if all alarms processed without errors |
| `processedCount` | integer | Total number of alarms in the request |
| `createdCount` | integer | Number of notifications created in database |
| `errors` | string[] | List of error messages (empty if success) |

### Error Response (400 Bad Request)

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.1",
  "title": "One or more validation errors occurred.",
  "status": 400,
  "errors": {
    "DeviceId": [
      "DeviceId is required."
    ]
  }
}
```

### Error Response (401 Unauthorized)

Device authentication token is missing or invalid.

```json
{
  "type": "https://tools.ietf.org/html/rfc9110#section-15.5.2",
  "title": "Unauthorized",
  "status": 401
}
```

## Behavior

### Duplicate Prevention

The endpoint checks for duplicate notifications within a 5-minute window. If the same alarm is reported multiple times:
- The existing notification's `occurrenceCount` is updated
- The `lastOccurredUtc` timestamp is updated
- No new notification record is created

### SignalR Notifications

When alarms with severity levels of WARNING, ERROR, or ALARM are created:
- Real-time notifications are sent to the site via SignalR
- Real-time notifications are sent to the device via SignalR
- Frontend clients connected to the appropriate hubs receive instant updates

### Additional Data Storage

All alarm details are stored in the `AdditionalData` JSON field, including:
- Severity, sourceDevice, category, messageKey
- Vendor code and alarm code
- Message parameters
- First/last occurrence timestamps
- Occurrence count
- Gateway ID and inverter serial number
- All raw register values (runStateRaw, warningWord1Raw, etc.)

## Example Usage

### cURL Example

```bash
curl -X POST https://api.yourdomain.com/api/device-notifications/alarm \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_DEVICE_TOKEN" \
  -d '{
    "deviceId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
    "alarmState": {
      "timestampUtc": "2025-12-21T20:30:00Z",
      "gatewayId": "EC100",
      "inverterSerialNumber": "INV-12345",
      "runStateRaw": 3,
      "warningWord1Raw": 0,
      "warningWord2Raw": 0,
      "faultWord1Raw": 16,
      "faultWord2Raw": 0,
      "faultWord3Raw": 0,
      "faultWord4Raw": 0,
      "activeAlarms": [
        {
          "code": 1005,
          "vendorCode": 4,
          "severity": "fault",
          "sourceDevice": "grid",
          "category": "ac_voltage",
          "messageKey": "GRID_VOLTAGE_HIGH",
          "messageParams": {},
          "firstOccurredUtc": "2025-12-21T20:29:45Z",
          "lastOccurredUtc": "2025-12-21T20:30:00Z",
          "occurrenceCount": 1
        }
      ]
    }
  }'
```

### C# Example

```csharp
var client = new HttpClient();
client.DefaultRequestHeaders.Authorization =
    new AuthenticationHeaderValue("Bearer", deviceToken);

var request = new ProcessDeviceAlarmCommand
{
    DeviceId = deviceId,
    AlarmState = new InverterAlarmStateDto
    {
        TimestampUtc = DateTime.UtcNow.ToString("o"),
        GatewayId = "EC100",
        InverterSerialNumber = "INV-12345",
        RunStateRaw = 3,
        FaultWord1Raw = 16,
        ActiveAlarms = new List<AlarmDto>
        {
            new AlarmDto
            {
                Code = 1005,
                VendorCode = 4,
                Severity = "fault",
                SourceDevice = "grid",
                Category = "ac_voltage",
                MessageKey = "GRID_VOLTAGE_HIGH",
                FirstOccurredUtc = DateTime.UtcNow.AddSeconds(-15).ToString("o"),
                LastOccurredUtc = DateTime.UtcNow.ToString("o"),
                OccurrenceCount = 1
            }
        }
    }
};

var json = JsonSerializer.Serialize(request);
var content = new StringContent(json, Encoding.UTF8, "application/json");
var response = await client.PostAsync(
    "https://api.yourdomain.com/api/device-notifications/alarm",
    content
);
```
